# office-judge-laugh

Entry for make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty.

One-line office joke, written to /output/entry.txt by main.py:

> I replied-all 'unsubscribe' to the 54th email about whose turn it was to clean the office fridge. HR called it hostile. Nobody has emailed me since. Best day of my career.

## Run it

```sh
mkdir -p output && MAKEFUN_OUTPUT_DIR=./output python3 main.py && cat output/entry.txt
```
